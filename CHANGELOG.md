# Changelog

All notable changes to the AI-Native Development Workflow will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive AI-native development workflow framework
- TypeScript/JavaScript project template with Vitest, ESLint, Prettier
- Python project template with Poetry, pytest, Ruff, Black, mypy
- React project template with modern best practices
- SPEC, ADR, and RFC templates for spec-driven development
- Cursor rules framework (project, user, overall rules)
- PR templates optimized for AI review workflows
- Code review guide with AI-assisted processes
- Prompt engineering guide with frameworks and slash commands
- Security policies and best practices guide
- Governance guide with branch protection and CODEOWNERS
- Dependency management configs (Renovate and Dependabot)
- GitHub Actions CI/CD workflows
- Pre-commit hooks and commit message validation
- Changelog management guide
- Comprehensive documentation structure

### Documentation
- ARCHITECTURE.md: System design and decision rationale

- GOVERNANCE.md: Repository governance and policies
- CODE_REVIEW.md: AI-assisted code review workflows
- PROMPT_GUIDE.md: Effective prompt engineering patterns
- CHANGELOG_GUIDE.md: Maintaining clear changelogs
- AI_RULES.md: Cursor rules, hooks, memory, and background agents
